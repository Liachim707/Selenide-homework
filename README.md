# Автоматизированное тестирование веб-страниц с Selenide

## Описание проекта

Этот проект — учебный Maven-проект на Java 17 для автоматизированного тестирования веб-интерфейсов с помощью **Selenide** и **JUnit 5**.

Тесты открывают веб-страницы в браузере, взаимодействуют с элементами интерфейса и проверяют, что страницы и формы работают ожидаемым образом. Проект демонстрирует применение паттерна **Page Object**: локаторы и действия со страницами вынесены в отдельные классы, а сами проверки находятся в тестовых классах.

## Что делает проект

В проекте автоматизированы проверки двух веб-страниц.

### 1. Динамическое меню jQuery UI

Проверяется страница: https://the-internet.herokuapp.com/jqueryui/menu

Тесты проверяют:
- отображение меню;
- появление вложенного меню при наведении курсора на пункты;
- отображение пунктов PDF, CSV и Excel;
- состояние доступности пунктов: PDF отключён на самой странице, CSV и Excel доступны.

### 2. Форма регистрации DemoQA

Проверяется страница: https://demoqa.com/automation-practice-form

Тесты проверяют:
- отображение основных полей формы;
- ввод имени, фамилии, электронной почты, номера телефона и адреса;
- выбор пола и хобби;
- ввод предмета и выбор его из списка автодополнения;
- HTML5-проверку обязательного поля имени;
- отправку корректно заполненной формы и появление окна с результатом отправки.

## Структура проекта

```text
selenide-homework/
├── pom.xml
├── README.md
└── src/
    ├── main/
    │   └── java/
    │       └── pages/
    │           ├── MenuPage.java
    │           └── FormPage.java
    └── test/
        └── java/
            └── tests/
                ├── MenuTests.java
                └── FormTests.java
```

Назначение основных файлов:
- `MenuPage.java` — Page Object страницы с динамическим меню.
- `FormPage.java` — Page Object формы DemoQA.
- `MenuTests.java` — автоматизированные тесты динамического меню.
- `FormTests.java` — автоматизированные тесты формы.
- `pom.xml` — зависимости проекта и настройки Maven.

## Как запустить проект

### 1. Установить необходимые программы

Перед запуском установите:
- JDK 17 или новее;
- Apache Maven 3.8 или новее;
- Google Chrome.

Проверьте, что Java и Maven доступны из командной строки:

```bash
java -version
mvn -version
```

### 2. Скачать проект

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/Liachim707/selenide-homework.git
cd selenide-homework
```

### 3. Запустить все тесты

Выполните команду из корневой папки проекта:

```bash
mvn clean test
```

Maven загрузит необходимые зависимости, скомпилирует проект и запустит тесты. Во время выполнения тестов Selenide будет управлять браузером Chrome. Для работы тестов требуется доступ к проверяемым сайтам.

### 4. Запустить отдельные наборы тестов

Только тесты меню:

```bash
mvn -Dtest=MenuTests test
```

Только тесты формы:

```bash
mvn -Dtest=FormTests test
```

## Результаты выполнения

После запуска Maven отчёты JUnit/Surefire сохраняются в каталоге:

```text
target/surefire-reports/
```

В случае ошибки откройте отчёт соответствующего тестового класса, чтобы посмотреть подробности.
